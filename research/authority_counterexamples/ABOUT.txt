# Intentionally failing local-only authority counterexamples

Run these explicit *negative* experiments from the repository root with the locked project environment:

```sh
uv run --locked --all-packages --group dev python -m pytest -o addopts= -q research/authority_counterexamples/test_unachievable_guarantees.py
```

**Expected exit status: nonzero (six failed tests).** Every test asserts a guarantee that a host-local authority cannot establish on its own: (1) detecting an internally consistent rollback, (2) globally electing between identical journal clones, (3) inferring physical writer identity from a copyable session, (4) authorizing a local effect through an unavailable local target, (5) inferring no effect from an unobservable lost reply, and (6) globally excluding a second full host clone with its own copied local target. The sixth experiment is especially important for fishhat's *no central or off-host host-ops/app-ops authority* rule: both machines can work safely on **their own local targets**, but no local-only theorem makes them one global writer.

These tests intentionally fail; do not turn them into xfails/skips or weaken the hypotheses to make the suite green. The positive portable experiment is `research/authority_reference/test_reference_safety.py`, and its model is `research/authority_reference/model.py`. Tests exercise SQLite on the current machine; they are not native physical-writer, cross-platform IPC, storage, OS, or application qualification. They remain outside default `tests/` discovery and maintained check-evidence inventory pending review.
